# 表情補給站 · Emoji Harbor

一個在本機運作的 Emoji 字型替換與選字盤擴充。

由使用者提出想法、測試與回饋，GPT 協助開發編寫。

**目前版本：1.3.5** · [更新紀錄](CHANGELOG.md) · [隱私聲明](PRIVACY.md)

## 可以做什麼？

- 切換網頁 Emoji 風格，並以 Noto 補足部分缺字。
- 從瀏覽器右上角開啟選字盤，搜尋中文、英文名稱或 Emoji，點選複製或嘗試插入目前輸入區。
- 選擇膚色、最近使用、預設分頁及四種選字盤大小；網頁 Emoji 尺寸可另外調整。
- 依網站停用，或排除不適合套用的網域。
- 五款工具列配色：燕麥奶茶、玫瑰歐蕾、舒眠花茶、灰岩拿鐵、深焙綠茶。

配色只影響右上角介面，設定、說明與測試頁維持原色。所有內建資源隨擴充提供，正常使用不需連線。

索引以 Emoji 18.0 為基礎，選字盤合併為 1,927 組圖案。索引版本不代表每家素材都已更新至相同版本；實際來源與覆蓋資訊見 [build-info.json](Chrome/build-info.json)。

## 安裝

### Chrome／Edge／Vivaldi／Brave

1. 解壓縮完整下載包，將 `Chrome` 資料夾放到固定位置。
2. 開啟瀏覽器的擴充管理頁，啟用「開發人員模式」。
3. 選擇「載入未封裝項目」，指定 `Chrome` 資料夾。
4. 將表情補給站釘選到工具列，開啟並選擇喜歡的字型。

請保留安裝資料夾，瀏覽器會持續從該位置讀取檔案。

### Firefox

需要 Firefox 142 或以上版本。

- **已簽署發布包**：開啟 `about:addons` → 齒輪 →「從檔案安裝附加元件」，選擇發布者提供的已簽署 XPI。
- **本包附帶的未簽署開發包**：開啟 `about:debugging#/runtime/this-firefox` →「載入暫時附加元件」，選擇 `Emoji-Harbor-Firefox-v1.3.5-unsigned.xpi`。重開 Firefox 後需要重新載入。

## 更新既有安裝

- **Chrome 系列**：把新版 `Chrome` 資料夾內容覆蓋到原安裝位置，再到擴充管理頁按「重新載入」。重新整理已開啟的網頁一次，以停用舊版內容腳本。
- **Firefox**：安裝對應的新版已簽署 XPI；暫時安裝則重新載入新版開發包。擴充 ID 保持相同，瀏覽器若保留儲存資料，偏好可沿用。

避免同時啟用兩份表情補給站。下載後也可開啟 [Start-Here.html](Start-Here.html) 閱讀完整說明。

## 使用與限制

工具列內可以直接選字型、調整網頁字形大小、搜尋與複製表情。齒輪開啟設定，水滴切換配色。

- 「直接插入」需網站編輯器配合；無法插入時可手動貼上。
- 動畫只改變自己的畫面，複製與傳送的內容仍是 Unicode 文字。
- 不更改網址列、分頁標題、瀏覽器內建頁面、受保護的擴充商店、圖片、影片或 Canvas 內容。
- 網站已經刪除的字元或實際寫入的「□」「�」無法推回原本 Emoji。
- Firefox 的字型格式與 Chrome 不同；1.3.5 針對舊符號回退及複合表情拆開修正字型映射，仍需實機確認。

## 本機資料與隱私

沒有帳號、遙測、瀏覽歷史紀錄、外部字型請求或自動下載。偏好、最近使用與匯入字型存在本機。

- **清除快取**：重建本工具的字型及選字盤快取，保留偏好與匯入字型。
- **清除本機資料**：清除匯入字型、最近使用及偏好，並暫停套用。

詳見 [隱私聲明](PRIVACY.md)。
