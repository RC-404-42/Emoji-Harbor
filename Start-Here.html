表情補給站

由使用者提出想法、測試與回饋，GPT 協助開發、編寫程式與整理使用說明。

表情補給站是一個可離線運作的 Chrome／Firefox 擴充，用來補齊新版 Emoji 字形，並依喜好切換風格、調整大小及挑選表情。它保留原始 Unicode 文字，不需要修改 Windows 系統字型，也不需要帳號或其他擴充。

內建六種靜態風格：Noto Color Emoji、Apple、Twemoji、Microsoft Fluent 3D、Microsoft Fluent 平面、OpenMoji；缺少的新圖案以 Noto Emoji 18.0 補齊，另有 230 個常用離線動畫。可匯入自己的彩色 Emoji 字型。

從工具列右上角開啟選字盤，即可搜尋、分類、選膚色或查看最近使用。每組圖案只顯示所選膚色；沒有膚色變體的表情維持原樣。複製與插入的仍是文字，對方裝置會決定它自己的外觀。

原創程式碼採 MIT；不同圖案與字型素材的授權各不相同。Apple 圖案不屬於本專案的 MIT 授權，備份與公開分享時請一併保留並確認 licenses 的素材說明。

初次安裝

Chrome／Edge／Vivaldi／Brave

  1. 解壓縮完整下載包，保留 Chrome 資料夾。
  2. Chrome 開啟 chrome://extensions，啟用「開發人員模式」。
  3. 按「載入未封裝項目」，選擇 Chrome 資料夾；這一層應看得到 manifest.json。
  4. 把圖示釘到工具列，並重新整理安裝前已開啟的網頁一次。

Edge 使用 edge://extensions；Vivaldi 使用 vivaldi://extensions；Brave 使用 brave://extensions。安裝後不要移動或刪除資料夾。

Firefox：XPI 安裝

  1. 取得發布者提供的已簽署 XPI，不需解壓縮。
  2. 開啟 about:addons，按齒輪 →「從檔案安裝附加元件」。
  3. 選擇 XPI，依提示確認權限並安裝；將圖示釘到工具列。
  4. 重新整理安裝前已開啟的網頁一次。
測試尚未簽署的開發包

本次提供的 Emoji-Harbor-Firefox-v1.1.4-unsigned.xpi 尚未簽署。請用 about:debugging#/runtime/this-firefox →「載入暫用附加元件」選擇此 XPI；完全退出再重開 Firefox 後需重新載入。一般安裝流程只接受已簽署的發布包。

本機 HTML 測試另需開啟 Chrome 擴充詳細設定的「允許存取檔案網址」。受保護頁面或其他擴充視窗不能由本工具修改。

如何更新

Chrome：把新版 Chrome 資料夾內全部檔案覆蓋到原本安裝的位置，保留舊資料夾路徑，再到擴充管理頁按「重新載入」。更新後首次重整已開啟的網頁一次，之後切換字形與尺寸不需每次重整。若使用不同資料夾另裝一份，請先停用舊版，避免兩版同時改字型。

Firefox：已簽署發布包依初次安裝方式安裝新版；暫用開發包先移除目前的暫用版本，再載入新版 XPI。擴充 ID 保持相同，瀏覽器若保留既有儲存資料，設定可沿用；清除資料或重設設定檔仍會重設偏好。

1.1.0 功能紀錄
  • 切換風格會直接通知已開啟的分頁；既有文字共用固定字型名稱，避免整頁先還原再套用。
  • 字形尺寸 60%–180%，以 5% 為單位。使用字型的 size-adjust 縮放，只影響 Emoji，保留中文、英數原本的字級。第一次切換尚未快取的大型字型可能短暫顯示「正在套用」。
  • 右上角直接開啟完整選字盤，支援搜尋、分類、上一頁／下一頁與最近 40 個表情。點選會複製 Unicode 文字；勾選「直接插入」時，也會嘗試插入剛才聚焦的輸入區。部分網站或特殊編輯器不接受插入，仍可手動貼上。
  • 六種內建靜態風格：Noto Color Emoji、Apple、Twemoji、Microsoft Fluent 3D、Microsoft Fluent 平面、OpenMoji。缺少的新圖案由 Noto 18.0 補齊。
  • Noto Animated：內建 230 個常用動畫。選字盤可預覽，在支援的網頁閱讀區也會播放；其餘圖案、輸入區、尚未載入成功的動畫都保留靜態 Noto。動畫只影響自己的顯示，複製出去仍是文字。
  • 其他匯入：可在設定頁匯入自己的 TTF、OTF、WOFF、WOFF2 彩色字型，最多 40 MB；檔案只存本機，不上傳。移除時會切回 Noto。缺字後備與複合字形支援取決於該檔案本身，不能保證任意第三方字型都能完整合字。

動畫如何運作

動畫使用對準原始文字範圍的本機 WebP 圖層；不把網頁文字改成圖片節點，保留選取與複製內容。必須由瀏覽器支援 CSS Custom Highlight、文字範圍定位與建構式樣式表。功能不支援、動畫未載入或沒有對應素材時，原始靜態字形仍然可見。

同時最多處理 160 個附近可見的動畫；滾動後會重新計算。特殊的 CSS 變形、持續移動的元件、文字直排、複雜遮罩、封閉 Shadow DOM 和部分瀏覽器實作可能造成對齊不準。若特定網站不合適，可在設定取消「Noto Animated 在網頁閱讀區播放動畫」，仍可在選字盤預覽；也可以排除該網站。

字形尺寸會改變排版所用的 Emoji 寬度，因此可能影響換行位置；不會修改旁邊中文和英數的 font-size。內建靜態圖案為 64px 點陣字型，動畫也為 64px，大幅放大不如向量圖銳利。

套用範圍與排除

支援一般網頁文字、動態內容、一般 iframe、可存取的 open Shadow DOM，以及文字輸入框與可編輯區。密碼欄位不改字型、不插入文字。全域停用或排除網站會還原本工具寫入的字型設定；直接移除整個擴充時，已開啟的分頁請重新整理。

排除清單一行一個網域，例如 example.com 也涵蓋 www.example.com。跨網域 iframe 依自己的網域判斷。若目前網站是被上層網域排除，按「啟用此網站」會移除那筆上層網域規則。

無法更改網址列、分頁標題、Windows 表情選字盤、其他擴充的視窗、Chrome Web Store、addons.mozilla.org、Canvas、WebGL、影片、貼圖或圖片 Emoji。網站若已把原文換成真正「□」或「�」字元，也不能猜回原本的 Emoji。鍵帽數字、©、® 或少數文字符號可能沿用系統字形，以保留一般數字排版。

權限與資料

網站存取用來定位文字、套用字型，以及在你點選時插入表情。scripting 用來啟用安裝前已開啟的網頁。storage 儲存設定與最近使用；unlimitedStorage 供匯入的大型本機字型使用；activeTab 用於確認目前分頁。沒有帳號同步、遙測、瀏覽歷史紀錄、外部字型 CDN 或自動下載。

所有內建字型、動畫與索引都隨包附上，使用時完全離線。素材版本、來源與各自的條款保留在 licenses 和 build-info.json；原創程式碼採 MIT，這不會改變其他圖案的權利。

隱私聲明

適用版本：1.1.4｜更新日期：2026-10-26

本聲明說明「表情補給站 Emoji Harbor」原始離線版本如何處理資料。第三方修改或重新打包的版本可能有不同行為，應由其提供者另行說明。

資料是否傳到外部

本擴充沒有營運伺服器、帳號系統、分析追蹤、廣告、遙測或自動回報。內建字型、動畫與索引都隨檔案提供，執行時不使用外部字型 CDN，也不呼叫 Chrome／Mozilla 帳號同步服務。匯入的字型不會上傳。使用者自行造訪網站、下載頁或 GitHub 產生的流量，屬於該網站與瀏覽器本身的行為。

為完成功能而在本機處理的內容

  • 替換字形及對齊動畫時，會在目前分頁檢查文字節點、Emoji、樣式與顯示位置。這些內容不會寫成網頁內容資料庫或瀏覽歷史，也不會傳送給外部服務。
  • 只有你點選插入表情時，才會讀取目標文字輸入區當下的內容及選取位置，並插入所選 Emoji。密碼欄位不處理；不建立按鍵紀錄。
  • 點選複製時會把所選 Emoji 寫入系統剪貼簿；本擴充不讀取剪貼簿內容。

會保存哪些資料

  • 本機設定：啟用狀態、風格、字形尺寸、膚色、輸入區與程式碼區開關、直接插入及動畫偏好，以及你設定的排除網域。
  • 最近使用：最多 40 個點選過的 Emoji；不保存搜尋文字、網頁輸入內容、完整網址或對話。
  • 自訂字型：只有自行匯入時，才保存檔案名稱、大小、檔案資料與本機識別版本。
  • 工作階段暫存：直接插入功能會暫存最近聚焦的分頁與內嵌框架識別碼，用於把 Emoji 送到正確的輸入區；不包含帳號密碼或網頁輸入內容。

這些資料保存在該瀏覽器的擴充儲存空間或目前作用中的記憶體。若使用者自行備份、同步或搬移整個瀏覽器設定檔，相關本機資料也可能被一併帶走；這不是本擴充主動上傳。

權限用途

網站存取與 scripting 用於在允許的分頁替換字型、定位文字及按你的操作插入表情；activeTab 用於目前分頁操作；storage 與 unlimitedStorage 用來保存上述本機偏好、最近使用與大型自訂字型。這些權限不會用於建立瀏覽歷史或販售資料。

如何清除與停止

設定頁可個別清除最近使用、移除匯入字型或清空排除清單。也可按「清除本機資料並暫停」，重設偏好、清除排除清單、最近使用、匯入字型與工作階段識別暫存；清除後保留最小的已暫停預設狀態，並關閉直接插入。

已載入的字型與目前分頁內的暫存物件，可能要等分頁重整或關閉後才完全釋放。清除擴充資料不會清除系統剪貼簿，也不會撤回已插入網頁的文字。直接移除擴充後，請重新整理原本的分頁；Firefox 的暫時移除可能保留同一擴充 ID 的資料，因此建議先使用設定頁的清除功能。
