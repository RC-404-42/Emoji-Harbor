隱私聲明

適用版本：1.3.4｜更新日期：2026-10-28

本聲明說明「表情補給站 Emoji Harbor」原始離線版本如何處理資料。第三方修改或重新打包的版本可能有不同行為，應由其提供者另行說明。

資料是否傳到外部

本擴充沒有營運伺服器、帳號系統、分析追蹤、廣告、遙測或自動回報。內建字型、動畫與索引都隨檔案提供，執行時不使用外部字型 CDN，也不呼叫 Chrome／Mozilla 帳號同步服務。匯入的字型不會上傳。使用者自行造訪網站、下載頁或 GitHub 產生的流量，屬於該網站與瀏覽器本身的行為。

為完成功能而在本機處理的內容

  • 替換字形及對齊動畫時，會在目前分頁檢查文字節點、Emoji、樣式與顯示位置。這些內容不會寫成網頁內容資料庫或瀏覽歷史，也不會傳送給外部服務。
  • 只有你點選插入表情時，才會讀取目標文字輸入區當下的內容及選取位置，並插入所選 Emoji。密碼欄位不處理；不建立按鍵紀錄。
  • 點選複製時會把所選 Emoji 寫入系統剪貼簿；本擴充不讀取剪貼簿內容。

會保存哪些資料

  • 本機設定：啟用狀態、風格、字形尺寸、膚色、輸入區與程式碼區開關、直接插入及動畫偏好，以及你設定的排除網域。
  • 最近使用：最多 40 個點選過的 Emoji；不保存搜尋文字、網頁輸入內容、完整網址或對話。
  • 自訂字型：只有自行匯入時，才保存檔案名稱、大小、檔案資料與本機識別版本。
  • 工作階段暫存：直接插入功能會暫存最近聚焦的分頁與內嵌框架識別碼，用於把 Emoji 送到正確的輸入區；不包含帳號密碼或網頁輸入內容。

這些資料保存在該瀏覽器的擴充儲存空間或目前作用中的記憶體。若使用者自行備份、同步或搬移整個瀏覽器設定檔，相關本機資料也可能被一併帶走；這不是本擴充主動上傳。

權限用途

網站存取與 scripting 用於在允許的分頁替換字型、定位文字及按你的操作插入表情；activeTab 用於目前分頁操作；storage 與 unlimitedStorage 用來保存上述本機偏好、最近使用與大型自訂字型。這些權限不會用於建立瀏覽歷史或販售資料。

如何清除與停止

設定頁可個別清除最近使用、移除匯入字型或清空排除清單。也可按「清除本機資料並暫停」，重設偏好、清除排除清單、最近使用、匯入字型與工作階段識別暫存；清除後保留最小的已暫停預設狀態，並關閉直接插入。

已載入的字型與目前分頁內的暫存物件，可能要等分頁重整或關閉後才完全釋放。清除擴充資料不會清除系統剪貼簿，也不會撤回已插入網頁的文字。直接移除擴充後，請重新整理原本的分頁；Firefox 的暫時移除可能保留同一擴充 ID 的資料，因此建議先使用設定頁的清除功能。
